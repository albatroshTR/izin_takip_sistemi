# Güvenlik

Bir güvenlik açığı bulduysanız lütfen herkese açık issue açmayın; depo sahibine GitHub'ın *Security › Report a vulnerability*
(özel güvenlik bildirimi) özelliğiyle ulaşın.

Programın güvenlik modeli ve sınırları: [docs/KULLANIM.md › Güvenlik](docs/KULLANIM.md#güvenlik). Özetle: veri dosyası ve yedekler parola ya da
kurtarma anahtarı olmadan okunamaz ve değiştirilemez; PDF / Excel çıktıları şifresizdir; program açıkken bilgisayara erişen biri ekranı görebilir.
